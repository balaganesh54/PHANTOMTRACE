PHANTOMTRACE — AI-Assisted Email Threat Detection & Cyber Forensics Web Platform. Built a full-stack SOC investigation prototype using Next.js, React, TypeScript, Tailwind, FastAPI, SQLAlchemy and PostgreSQL. Implemented safe `.eml` parsing, IOC extraction, SPF/DKIM/DMARC analysis, explainable risk scoring, MITRE ATT&CK evidence mapping, threat visualization, audit logging and PDF forensic reporting with reproducible demo mode.
